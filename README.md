# 트리플스트리트 QR 가이드맵

송도 트리플스트리트 고객이 매장 곳곳의 QR을 휴대폰으로 스캔하면 **현재 위치**가 층별 지도에 표시되고, 가고 싶은 곳을 누르면 **층을 넘나드는 경로**를 선으로 안내하는 모바일 웹 가이드맵입니다.

## 주요 기능

- **QR 스캔 → 현재 위치 표시**: QR마다 고유 주소(`#1f-1` 등)가 있어서, 스캔하면 해당 층 지도가 열리고 현재 위치가 빨간 점으로 표시돼요.
- **층별 지도 4개 탭**: 2026-08-26 가이드맵 PDF에서 층별 도면을 잘라 4개 탭으로 나눴어요.

  | 탭 | 구역 | 비고 |
  |---|---|---|
  | 1F | 송도 가로수길 · 세고비아 8번가 | |
  | 2F | 하바나 2번가 · 송도주가 · 송도놀이터 | |
  | B1–B3 | 나폴리 1번가 · 메이플파크 | A·C동 B2, B동 B3, D동 B1 |
  | 3–6F | 골든파크 · 메가박스 | 5F·6F는 D동 |

- **길 안내**: 매장을 검색하거나 지도의 아무 곳이나 누르면 최단 경로를 계산해서 선으로 그려요. 다른 층이면 엘리베이터나 에스컬레이터 탑승 단계까지 함께 안내해요.
- **매장 검색 · 분류**: 가이드맵 층별 안내의 전체 매장 185곳(여러 층 매장 포함 205개 위치)과 편의시설 34곳을 패션 / 푸드·카페 / 즐길거리 / 생활 / 편의시설(화장실, 안내데스크, ATM)로 나눠 볼 수 있어요.
- **확대 · 이동**: 두 손가락 확대, 드래그 이동, 마우스 휠을 지원해요.
- **다크 모드**: 휴대폰 설정을 따라가요.

## 구조

외부 서버나 빌드 과정 없이 `index.html` 파일 하나로 동작해요. 층별 지도 이미지 4장은 WebP로 HTML 안에 들어 있어요(약 0.4MB).

```
triple-street-guide-map/
├── index.html      # 앱 전체 (지도 이미지 · 데이터 · 화면 · 경로 계산)
├── README.md
└── docs/           # README용 스크린샷
```

`index.html`의 `<script>` 안에 있는 데이터만 고치면 내용이 바뀌어요. 좌표는 모두 **지도 이미지 가로 2000px 기준 픽셀**이에요.

| 데이터 | 역할 |
|---|---|
| `PANELS` | 층 탭 4개 (이름, 부제, 이미지 크기) |
| `N` | 통로 경로망의 점: `id: [탭, x, y]` (탭: `'1F' 'B' 'U'` 등) |
| `CHAINS` | 점들을 순서대로 이은 통로 선 |
| `LIFTS` | 엘리베이터 · 에스컬레이터. 엘리베이터는 운행층끼리 바로 연결하고, 에스컬레이터는 `m` 배열 순서대로 **한 층씩만** 연결해요 (아래층 → 위층 순서로 적기) |
| `QRS` | QR 지점 21곳 (코드, 탭, 좌표, 이름, 설명) |
| `QR_ALIAS` | 예전 QR 주소 호환표 |
| `POI` | 검색 · 목적지 239곳 `[이름, 탭, x, y, 분류]` (가이드맵 2페이지 층별 안내 기준) |

**경로 계산 방식**: 출발점과 목적지를 가장 가까운 통로 선에 붙인 다음, 다익스트라(Dijkstra) 최단 경로를 구해요. 층간 이동 비용은 엘리베이터 320, 에스컬레이터 한 층당 240(픽셀 단위 가중치)이에요. 같은 에스컬레이터로 여러 층을 이어 타면 안내에서는 한 단계로 묶어 보여 줘요.

**검증**: QR 21곳 × 목적지 239곳 = 5,019개 경로가 모두 계산되는지 확인했어요 (2026-10-01).

## 수정하는 법

1. `#admin`으로 열고 **좌표 편집 도구 → 경로망 표시 켜기**를 눌러요.
2. 지도를 누르면 `['1F', 1234, 456]` 형식의 좌표가 기록돼요. **좌표 복사**로 가져와요.
3. GitHub에서 `index.html` → 연필(✏️) 아이콘을 눌러 해당 데이터를 고쳐요.
   - **QR 추가**: `QRS`에 `{id:'1f-6', p:'1F', x:…, y:…, name:'…', desc:'…'}` 한 줄 추가
   - **매장 추가 · 변경**: `POI`에 `['매장명','2F',x,y,'food']` 수정
   - **통로 보정**: `N`의 좌표를 옮기거나 새 점을 만들고 `CHAINS`에 연결
4. **Commit changes**를 누르면 1~2분 뒤 사이트에 반영돼요. QR 주소는 그대로예요.

> 수정이 바로 안 보이면 **Ctrl + Shift + R**(강력 새로고침)이나 시크릿 창으로 확인하세요. GitHub Pages는 최대 10분 정도 캐시를 유지해요.
